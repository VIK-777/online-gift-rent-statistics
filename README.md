# Telegram Gifts Rent Tracker 🎁

> Легковесное веб-приложение для отслеживания Telegram-подарков в аренде.  
> **100% Client-Side:** работает в браузере **полностью без бэкенда** и **без необходимости вводить API-ключ**.

---

## ✨ Особенности

* 📱 **Mobile-First дизайн:** идеально оптимизировано под смартфоны, адаптировано под вырезы экрана (notch) и Telegram Mini App.
* ⚡ **Без бэкенда (Serverless / SPA):** все запросы к блокчейну TON и смарт-контрактам выполняются прямо из браузера клиента.
* 🔑 **Работает без API ключа:** встроена умная очередь запросов (Rate Limiter ~1 RPS) с автоматическим повтором при `429 Too Many Requests`.
* ⏱️ **Живые таймеры:** обратный отсчет до возврата каждого подарка в реальном времени.
* 💰 **Финансовая аналитика:**
  * Общая сумма заработка в TON и USD.
  * Сколько заработано конкретно с каждого подарка.
  * Количество завершенных и текущих аренд.
  * Детальная история выплат со ссылками на транзакции в Tonviewer.
* 📦 **Поддержка смарт-контрактов:** автоматический парсинг BoC ячеек смарт-контрактов **MarketApp (MRKT)** и **Tonnel**.
* 💾 **Мгновенный локальный кэш:** при повторном открытии кошелька данные появляются за 0.01 секунды из `localStorage`.

## 🚀 Быстрый запуск локально

1. Перейдите в папку проекта:
   ```bash
   cd online-gift-rent-statistics
   ```

2. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```

3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
   Откройте появившуюся ссылку (обычно `http://localhost:5173`).

## 🌐 Бесплатное развертывание в интернете

Поскольку сайт статичен и не требует бэкенда, его можно бесплатно опубликовать на любой из платформ:

### 1. GitHub Pages (Бесплатно)
1. Создайте репозиторий на GitHub и загрузите проект.
2. В `Settings` -> `Pages` выберите источник **GitHub Actions** или ветку `dist`.

### 2. Cloudflare Pages или Vercel (Развертывание в 1 клик)
1. Подключите ваш GitHub репозиторий.
2. Framework preset: **Vite**.
3. Build command: `npm run build`.
4. Output directory: `dist`.

### 3. Telegram Mini App (TMA)
После публикации ссылки на Vercel/Cloudflare:
1. Откройте в Telegram бота `@BotFather`.
2. Вызовите команду `/newapp`, выберите своего бота и укажите URL сайта.
3. Теперь ваши пользователи смогут открывать трекер подарков прямо внутри Telegram!

## ⚙️ Опциональные настройки

В правом верхнем углу сайта есть кнопка **Настройки** (шестеренка):
* **Свой ключ TonAPI (опционально):** если у вас есть бесплатный персональный ключ с [tonconsole.com](https://tonconsole.com), вы можете вставить его туда. Ключ сохранится только в вашем личном браузере, увеличив лимит параллельных запросов.
* **Очистить кэш:** сбрасывает сохраненные снимки кошельков.
